# Лабораторная работа 1

## Сбор, визуализация и анализ данных по графу

Решение: [lab1.ipynb](lab1.ipynb). Данные: [papers.csv](papers.csv).

## Задание

1. Выбрать тематику научных публикаций, любую область знаний, например, machine learning или artificial intelligence. Лучше брать что-то более узкое и интересное вам.
2. Скачать с [arXiv](https://arxiv.org/) данные о научных публикациях по выбранной тематике. Выгрузить названия, авторов и аннотации статей. Скачивать через [API arXiv](https://info.arxiv.org/help/api/user-manual.html). Не менее 300 публикаций. Публикации должны быть не старше 2020 года.
3. Провести разведочный анализ данных собранного корпуса текстов. Построить визуализации, в частности для проверки закона Ципфа.
4. Выделить ключевые слова по каждой публикации (используйте названия и аннотации). Обратите внимание, что тут речь идет не только об униграммах, могут быть рассмотрены биграммы, триграммы. Не забывайте делать нормализацию.
5. Построить связи между ключевыми словами на основе их принадлежности публикациям с использованием библиотеки [NetworkX](https://networkx.org/).
6. Определить кластеры ключевых слов на графе. Оценить качество кластеризации (например, по модулярности). Интерпретировать результат кластеризации, то есть объяснить, какие ключевые слова попали в кластеры и почему.
7. Найти ключевые слова с наибольшими значениями центральности в выбранной тематике (например, degree centrality, betweenness centrality, eigenvector centrality, closeness centrality). Найти не менее трех разных значений центральностей. Интерпретировать результаты.
8. Построить граф публикаций: если ключевое слово является тегом для двух публикаций, значит, между ними связь есть. Чем больше общих ключевых слов, тем сильнее связь (выше вес ребра). Реализовать поиск наиболее близких к заданной пользователем публикаций на графе.
9. Реализовать и протестировать поиск публикаций по графу публикаций.

## Критерии оценки

1. **Сбор данных и выделение ключевых слов (пункты 1–2) — 10 баллов.** Оценивается оригинальность выбранной тематики, актуальность публикаций, качество построения визуализаций, полнота и логика описания данных в отчете.
2. **Построение и анализ графа ключевых слов — 12 баллов.** Оценивается полнота проведенного анализа, корректность реализации и интерпретация результатов.
3. **Поиск по графу публикаций — 8 баллов.** Оценивается подход к поиску и корректность его реализации, полнота и логика описания решения в отчете.
